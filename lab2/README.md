### Короткий опис завдань

* **Завдання 1:** Обчислення характеристик масиву (сума, середнє, min/max з індексами, кількість нулів) за один прохід.


* **Завдання 2:** Фільтрація елементів, більших за $K \pmod 5 = 3$, у новий масив точного розміру.


* **Завдання 3:** Пошук найдовшої серії однакових елементів, що йдуть підряд.


* **Завдання 4:** Циклічний зсув елементів масиву вліво на 1 позицію на місці.


* **Завдання 5:** Обробка двовимірного масиву ($3 \times 6$): обчислення сум рядків, максимумів стовпців та пошук рядка з найбільшою сумою.

### Завдання 6. Таблиця перевірки крайових випадків

| Вхід | Завд. | Очікувано | Отримано | Виправлення |
| :--- | :--- | :--- | :--- | :--- |
| **Порожній** (`new int[0]`) | 1–4 | Без помилок | «Порожній масив» | Додано `if (arr == null \|\| arr.Length == 0)` |
| **1 елемент** (`new int[] {4}`) | 1–4 | Min=Max=4, зсув без змін | Min=Max=4, зсув `[4]` | Додано `if (arr.Length <= 1) return;` |
| **Усі однакові** (`new int[] {2,2}`) | 1, 3 | Серія = довжині масиву | Значення 2, довжина 2 | Перевірка серії після циклу |
